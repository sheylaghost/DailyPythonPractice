## 🇧🇷 Português

Dada uma lista de palavras, encontre as 3 palavras mais frequentes.

Regras:

* Conte quantas vezes cada palavra aparece.
* Ordene por frequência em ordem decrescente.
* Em caso de empate, ordene alfabeticamente.
* Retorne apenas as 3 palavras mais frequentes (ou menos, caso não existam 3 palavras distintas).

Exemplo:

Entrada:
["python", "java", "python", "c", "java", "python"]

Saída:
["python", "java", "c"]

---

## 🇺🇸 English

Given a list of words, find the 3 most frequent words.

Rules:

* Count how many times each word appears.
* Sort by frequency in descending order.
* If two words have the same frequency, sort them alphabetically.
* Return only the 3 most frequent words (or fewer if there are less than 3 unique words).

Example:

Input:
["python", "java", "python", "c", "java", "python"]

Output:
["python", "java", "c"]
